# Algoritmos y Programación II - Cátedra Buchwald 💻

Repositorio con la implementación de estructuras de datos fundamentales y algoritmos de búsqueda y ordenamiento, enfocados en la eficiencia temporal y espacial.

## 🛠️ Estructuras Implementadas (Go)

Todas las estructuras cuentan con un análisis de complejidad constante o logarítmica según corresponda y fueron validadas con pruebas unitarias (go test).

- TDAs Básicos:
  - Pila
  - Cola
  - Lista Enlazada.

- TDAs No Lineales:

  - ABB (Árbol Binario de Búsqueda): Implementación de iteradores internos y externos.
  - Heap: Implementación de cola de prioridad con heapify y algoritmo de ordenamiento HeapSort.
  - Diccionario (Hash): Tabla de hash abierta/cerrada con redimensionamiento dinámico.

## 🚀 Trabajos Prácticos

- Calculadora Polaca Inversa (Go): Procesamiento de expresiones matemáticas utilizando el TDA Pila.
- Detector de Logs (Go): Sistema eficiente de filtrado y procesamiento de grandes volúmenes de logs.
- Red de Delincuencia (Python): Modelado de interacciones criminales mediante Grafos. Implementación de algoritmos de caminos mínimos, componentes fuertemente conexas y centralidad.

## 📊 Conceptos Clave
- Análisis de Complejidad: Notación Big-O (O(1), O(log n), O(n)).
- Manejo de Punteros: Gestión eficiente de memoria en Go.
- Paradigma Funcional: Uso de funciones como ciudadanos de primera clase para iteradores y comparadores.
